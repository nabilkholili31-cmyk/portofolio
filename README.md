# Portofolio Faiq — Teman Mahasiswa

Landing page portofolio interaktif dan responsif untuk **Faiq (Teman Mahasiswa & Digital Creator)**, mahasiswa aktif **UMNU (Universitas Ma'arif Nahdlatul Ulama Kebumen)** yang berdomisili di Jatimulyo, Alian, Kebumen (lingkungan Al-Hasani Jatimulyo).

## 🚀 Layanan & Program
1. **Desain Vektor Promosi Makanan:** Feed Instagram, menu kuliner, katalog visual produk.
2. **Banner Promosi & Spanduk Event:** Desain siap cetak resolusi tinggi untuk toko & acara.
3. **Desain Kaos & Apparel:** Streetwear artwork, t-shirt mockup, dan file vector siap sablon.
4. **Video Konten Promosi Berbasis AI:** Video reels/TikTok estetik untuk showcase produk & menu.
5. **Pelatihan / Mentoring Praktis Canva:** Khusus tatap muka langsung (offline) di Kebumen & sekitarnya.

## 🛠️ Tech Stack
- **HTML5 & Semantic Elements**
- **Tailwind CSS** (via CDN)
- **Lucide Icons**
- **Vanilla JavaScript** (Kalkulator estimasi dinamis, modal, filter portofolio, mobile drawer)
